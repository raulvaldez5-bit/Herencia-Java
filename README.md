# Herencia-Java
Actividad Formativa 3 Herencia en Java
## Descripción del proyecto

Actividad Formativa 3: Herencia en Java.

El proyecto demuestra el uso de la programación orientada a objetos mediante una clase base llamada Empleado y dos clases derivadas: Docente y Administrativo.

Se aplican los siguientes conceptos:

- Herencia mediante `extends`.
- Reutilización de constructores y métodos con `super`.
- Sobrescritura de métodos mediante `@Override`.
- Creación de objetos de las clases derivadas.
- Ejecución de métodos heredados y exclusivos.

El programa fue desarrollado y probado en IntelliJ IDEA.
